Accept / Cancel Match

Only party_b can accept, and only before kickoff. Only party_a can cancel, and only before acceptance.

Propose Resolution — Phase 1

Permissionless. Only callable after the resolution deadline and before the resolution window closes. Every committed required domain must be represented. If evidence doesn't clear the quality bar, nothing locks and the match stays open for a retry.

Challenge Resolution — Phase 2

Only party_a or party_b, only during the challenge window, only with a concrete counter-evidence URL, bounded to a fixed number of rounds. Re-runs full consensus over the locked set plus your source; only changes anything if the verdict actually moves.

Finalize Match

Permissionless. Locks in the current provisional verdict once the challenge window has closed — always terminal, never stuck, even on a Disputed/Indeterminate verdict (which finalizes as a refund).

Expire Match

Permissionless. Moves a lapsed pre-proposal match (never accepted before kickoff, or never got a quality-clearing proposal before the resolution window closed) to "expired".

Read Match

Full auditable record: canonical fixture identity, parties, timing, current status, locked evidence, and (once finalized) the final verdict and settlement.
